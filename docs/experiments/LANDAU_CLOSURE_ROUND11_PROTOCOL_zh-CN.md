# Round 11：有记忆的流体热流闭合

用户于 2026-09-07 授权按本任务讨论顺序执行。目标是通过低阶流体方程与神经高阶闭合，提高完整非线性演化精度并测量实际加速。所有新产物使用独立的 round11 路径，既有原始数据和实验结果保留。

## 执行顺序与阶段门

1. 在 canonical train/validation 的代表案例上，用真实、随时间变化的热流驱动流体求解器；比较 mode 8/16/24，再检查时间步收敛。若真实闭合也失败，先定位和修复离散系统，不能直接开始学习闭合。
2. 建立实际物理时间插值的历史窗口；只读取矩诊断。保留 139 train / 20 validation，现有 36 test 为已打开的开发诊断集。
3. 同一 FNO 主干、求解器及训练预算比较 A：当前 U+K；B：历史 U+K；C：历史 U+K+alpha。U=(n,u,p,E)，直接输出零均值的热流梯度。不输入绝对时间。
4. 监督预训练后进行连续多步反传，物理时长课程 0.2 -> 1 -> 2。每轮覆盖所有训练案例，均衡物理阶段。使用梯度检查点，窗口内部不 detach，不以稳定代替准确。
5. 小规模 pilot 使用 validation 冻结历史跨度（0.5/2/5）、数值设置；正式 A/B/C 三随机种子。在完整 t=80 validation 上选模，记录所有失败，禁止用提前终止缩短误差区间。
6. 准确模型进入低频闭合更新及网络压缩实验，再在同硬件、批量、输出频率下测端到端时间。
7. 冻结模型和阈值后，新增独立参数盲测；如三矩路线未达到质量门，记录负结果并开展增加演化矩数的条件实验，不把不合格模型当成成功闭合。

## 约束和评价

- 起始历史的填充及有效性标记在训练与部署一致。正式从初态推进不回灌真实历史或真实热流；oracle 检查单独标记。
- 归一化仅使用训练集。alpha 作为模型输入只出现在 C；所有模型使用相同的采样和损失尺度。
- 训练/目标/部署频带一致。热流梯度空间均值恒为零；额外离散源项若必要，必须明确区分及核算守恒。
- 损失包含扰动状态、复电场低模、带地板的 log 场能、辅助监督闭合、正性及守恒。不采用旧版 off-manifold state -> contemporaneous truth heat-flux 的 recovery 标签。
- 保存完整矩场、电场、闭合、守恒、正性违规、失败时间、网络调用次数、端到端墙钟时间。相位指标只在有效信号区间计算。
- 物理失效案例独立报告；全程指标只在完成的相同案例及固定时间区间比较。选模优先物理有效性，再评价场能、相位和扰动状态，避免单一混合分数掩盖退化。
- 正式神经训练使用 CUDA，初始选择空闲物理 GPU 6，CPU 限制为 2 核；资源发生变化时记录并调整，不影响其他运行任务。

## 科学结论边界

K 或等价尺度信息是当前统一参考域表示所需；alpha 的必要性尚未得到单因素消融支持。历史跨度和增加矩数均为待验证假设。计算必须经过前一阶段的质量检查才能推进，不能仅为完成预定流水线跳过失败。

## Pilot 期间的诊断补充（2026-09-07）

- A 组首先完成：候选全程验证显示失稳，短窗分数不能作为闭环质量结论。报告另外给出 t=30..80 的固定区间指标，以及共同完成案例的逐案例差值。
- 质量阈值见 `configs/training/continuum_history_closure_round11_quality.json`，在 B/C pilot 与全部正式结果产生前固定。这是本轮暂定工程验收线，并非普遍物理标准，也不是事前注册的科学结论。正式模型要求三种子均通过才进入加速及盲测。
- 参考数据保持 x,v -> -x,-v 反射对称；A 自由推进出现显著不对称分量。单独进行同一冻结检查点的反射等变化和频带诊断。原始 pilot 不回改；正式设置若修改，以统一的 overrides 文件记录，A/B/C 同时采用，频带和 dt 必须重新通过 oracle 门。
- 反射等变闭合对任意输入定义为 [F(U)+R_g F(R_U U)]/2，其中 n,p 为标量，u,E 为反射变号的向量，g=dq/dx 为标量。实现使用双倍批量并明确记录开销；不是只把特定轨迹强行投影成偶函数。
- GPU 6 被其他任务占满后，本轮主训练转到 GPU 5；少量独立冻结模型诊断使用 GPU 2。共享 GPU 上的诊断时间不能用于最终加速比结论。
- 冻结模型的四项部署诊断完成数为：原始 mode 16 11/20、mode 8 12/20、反射约束 mode 16 14/20、反射约束 mode 8 18/20。误差比较必须使用共同完成案例，不能直接比较不同幸存集合的中位数。
- 进一步对完整未滤波矩场检查 oracle：mode 8 最大扰动相对误差 2.63%，mode 16 为 0.304%。补充的完整矩场 oracle 误差线为 1%；mode 8 不通过，此拒绝保留在 `oracle_gate_mode8.json`。正式设置保留 mode 16、dt=0.02，统一增加反射等变约束，见 `formal_overrides.json`。之前的 mode 8 暂定文件保留为 `rejected_tentative_mode8_overrides.json`，不用于正式训练。
- 三个随机种子共享既有监督检查点，改变采样时间与样本顺序；因此衡量的是训练随机性，不应称为三个完全独立的随机初始化。
- 数值 oracle 已扩展到全部 20 个 validation 案例，全部完成；相对未滤波参考矩场的最大扰动误差 0.812%，通过完整矩场 1% 的误差线。正式自由验证同时检查 RK 中间状态和接受状态的 n、p 正性；Round 11 右端不使用旧代码默认的密度分母下限。正常正密度下两种右端完全一致。原始 pilot 仍按其各自源快照保留。
- 后续控制器会等待正式九个结果，再进行闭合更新间隔 0.02/0.04/0.1 的有梯度微调及 width=64 的剪枝后重训。相对基准的三项后半程误差不得恶化超过 10%（另有 1e-4 绝对容差），并须满足原精度门。
- 12 个新增参数的配置已准备，未生成动力学真值。模型、质量线、生成配置和评估源码在生成前保存哈希和快照。盲测含 6 个内部点、2 个边界点、2 个 K 外推点、2 个 alpha 外推点；固定输出间隔 0.1，仅存首末分布帧，以减少新数据量。出现盲测失败不会用该盲测调参后重报。
- 计时分别记录常驻模型推进、数据传输与写盘、模型加载，以及 Gkeyll solver 统计。共享 GPU 的观测结果不等于独占硬件的严格基准；单例计时保持同硬件型号和相同矩场输出频率，并保留所有失败案例。
