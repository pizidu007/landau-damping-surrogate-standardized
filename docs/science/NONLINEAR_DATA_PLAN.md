# 强非线性 Landau 数据扩展方案

现有数据覆盖 `k=0.45..0.70`、`alpha=0.005..0.05`、`t=0..15`，主要用于
线性和弱非线性代理。新数据把时间延长到 `t=40`（pilot）和 `t=60`
（formal），并加入 `alpha=0.075..0.125` 以及论文锚点 `(k,alpha)=(0.35,0.1)`。

## 科学目标

1. 覆盖阻尼停止、粒子捕获、相空间空穴和非线性回弹；
2. 同时支持完整 `f(x,v,t)` 代理与 `(n,u,p)->d q/dx` 闭合研究；
3. 比较瞬时闭合和带时间历史的闭合；
4. 在未见 `(k,alpha)` 上做完整轨迹泛化，而不是随机切分时间帧。

## 生成器审计与修正

旧 CUDA 循环每一步都把电场、密度和标量同步回 CPU，长时间运行会产生大量
小传输和 CUDA 同步；新版把历史留在 GPU，单个 case 完成后一次性回传。

旧 quiet start 使用

```text
x = y - alpha/k * sin(k*y)
```

它只是目标密度 `1+alpha*cos(kx)` 的一阶近似。新版在 GPU 上用 Newton 法反演
精确 CDF：

```text
y = x + alpha/k * sin(k*x)
```

并直接从粒子以同一 CIC 核沉积 M0--M3。这样热流标签不再依赖只保 M0/M2 的
粗相空间缓存，也避免对带噪 `q` 先插值再差分。

## 执行门槛

正式数据开始前先完成 pilot 的 `dt=0.10/0.05`、粒子数和速度范围收敛比较。
接受标准至少包括：总能量漂移、相空间速度溢出、M0 一致性、M3/热流的 seed
方差，以及电场能量的阻尼、回弹和频率稳定性。
