# Gkeyll 三矩流体方程与闭环误差审计

## 结论

当前长期误差的重点确实在闭环推进，但不是 RK4、Poisson/Ampère 或三矩方程写错，而是学习闭合离开真值低阶矩流形后的反馈放大。

三矩方程在给定精确热通量后是 Vlasov 矩层级的精确前三式；问题在于有限历史的低阶矩并不能在任意偏离状态上唯一、稳定地决定动理学热通量。

## 方程检查

当前 primitive 系统为

\[
\partial_t n + \partial_x(nu)=0,
\]

\[
\partial_t u + u\partial_xu + n^{-1}\partial_xp = -E,
\]

\[
\partial_t p + u\partial_xp + 3p\partial_xu + \partial_xq=0.
\]

电子电荷为 `-1`，Gkeyll 初始场满足 `∂xE=1-n`，Ampère 更新为

\[
\partial_tE=nu-\langle nu\rangle.
\]

这些符号与 Gkeyll 配置一致。中心矩定义

\[
p=M_2-nu^2,\qquad q=M_3-3uM_2+2nu^3
\]

也与处理程序一致。新增的中心矩/原始矩 RHS 等价测试通过，流体相关 5 项测试全部通过。

## Gkeyll 真值闭合 oracle

将随时间变化的 Gkeyll 真值 `∂xq(t,x)` 直接输入流体方程，完整推进到 `t=40`：

| 案例 | 模数 | 场求解器 | dt | 状态相对误差 | 场能 log-RMSE |
|---|---:|---|---:|---:|---:|
| `k=.35,A=.075` | 8 | Poisson | 0.01 | 7.94e-6 | 7.83e-4 |
| `k=.35,A=.075` | 8 | Ampère | 0.01 | 7.96e-6 | 8.57e-4 |
| `k=.40,A=.10` | 8 | Poisson | 0.01 | 6.61e-6 | 9.24e-4 |
| `k=.40,A=.10` | 8 | Ampère | 0.01 | 7.13e-6 | 1.46e-3 |

真值轨迹的瞬时 PDE RHS 残差在 8 模下为 `1.31e-4` 和 `1.96e-4`，31 模下为 `5.99e-5` 和 `6.27e-5`。这说明方程、变量定义和空间导数与 Gkeyll 数据高度一致。

## 数值求解器排查

- 8 模下将 `dt=0.002` 改为 `0.01`，oracle 仍保持 `10^-3` 量级场能误差。
- 学习闭合下，`dt=0.002` 与 `dt=0.01` 的场能误差分别约为 `0.401/0.730` 与 `0.404/0.731`，几乎不变。
- 学习闭合下切换 Poisson/Ampère，场能误差差别小于 `4e-4`。
- Ampère 场能与由预测密度重新求解 Poisson 得到的场能，log-RMSE 只有 `6.1e-5` 和 `1.18e-4`。
- FNO 流体总能量相对变化范围只有 `1.26e-5` 和 `2.88e-5`，不存在足以解释长期场能误差的数值能量漂移。

因此，继续缩小时间步或更换场求解器不会解决当前主要问题。后续 rollout 训练反而可以安全使用 `dt=0.01`，将计算量降低约 5 倍。

## 闭环反馈误差

| 案例与区间 | 真值轨迹上的闭合误差 | 自身闭环轨迹相对真值时刻的闭合偏差 |
|---|---:|---:|
| `.35/.075`, `0–10` | 0.016 | 0.020 |
| `.35/.075`, `10–20` | 0.024 | 0.467 |
| `.35/.075`, `20–30` | 0.062 | 2.405 |
| `.35/.075`, `30–40` | 0.102 | 1.733 |
| `.40/.10`, `0–10` | 0.006 | 0.013 |
| `.40/.10`, `10–20` | 0.010 | 0.641 |
| `.40/.10`, `20–30` | 0.114 | 3.644 |
| `.40/.10`, `30–40` | 0.328 | 2.639 |

状态总体相对误差约在 `t=15–19` 超过 1%。之后闭合输入逐渐离开训练分布，模型输出与参考动力学闭合快速分离。晚期场能峰值分别约是真值的 1.8 倍和 2.9 倍，相位误差也持续增长。

## 下一轮训练建议

1. 使用验证过的 `dt=0.01` 和 Poisson 场，训练跨 `1–5` 时间单位、覆盖多个场能振荡周期的 rollout。
2. rollout 损失加入复数基模 `E_k` 的幅值与相位、峰值包络和转折时间，而不只使用局部状态 MSE。
3. 使用 scheduled sampling：历史窗口逐步从真值状态替换为模型状态，直接训练模型承受自身分布漂移。
4. 对输入加入与实际 rollout 偏差幅度相符的平滑扰动，并约束闭合对小状态扰动的敏感度，改善离开真值流形后的稳定性。
5. 将历史覆盖扩大到至少一个等离子体振荡周期，或加入可演化的隐变量；四帧 0.1 时间单位历史不足以表示粒子俘获记忆。
6. 保留当前三矩方程作为主线。只有长时 scheduled-sampling 仍失败时，再比较四矩系统或带记忆核的广义闭合，而不是先重写 PDE。
