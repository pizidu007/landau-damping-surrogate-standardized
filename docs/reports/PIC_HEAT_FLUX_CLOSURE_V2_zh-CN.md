# PIC–FNO 热流闭合第二轮实验报告

## 结论

第二轮实验完成了论文数据复核、同参数高粒子数 CUDA-PIC 对照、低噪声
标签训练、历史窗口 FNO、Poisson/Ampere 与步长消融、长时闭环筛选和
rollout 微调。

最重要的结论有三条：

1. Huang 公开数据可以复现极低的同轨迹插值误差，但这不能代表非线性
   时间外推能力。交错抽样 test 相对 L2 为 `0.00279`，改成严格因果的
   `t=30–40` test 后为 `0.33842`。
2. PIC 标签加入五帧历史后，validation 相对 L2 从单帧的 `0.23421`
   降到 `0.17271`，说明低阶矩到热流的映射具有明显的非马尔可夫性。
3. 更好的离线热流并未自动转化为更好的长时闭环。纯 history-FNO 在
   `t≈24–34` 失稳；75% HP 混合可稳定到 `t=60`，但场能 log10 RMSE
   为 `1.550`，差于 v1 部署模型的 `1.393`。因此本轮保留 v1 作为部署
   默认，把 v2 history-5 保存为研究模型。

## 1. 论文公开数据审计

Zenodo 记录只提供 `A005_data.mat` 与 `A01_data.mat`，没有训练或流体
闭环代码。两个文件字节完全相同，SHA-256 都是
`a8948c83ec76dee517c0d78fd40cc7bf88e3164351e335b70b4f9dd3ee3f69fc`；
它们的初始密度范围都是 `0.9–1.1`，实际均对应 `A=0.1`，因此公开资产
中没有可用的独立 `A=0.05` 轨迹。

数据文件没有时间元数据。由连续性方程反推的快照步长为 `0.00513`，
与论文所述 `0.005` 一致；论文图中的 `t=0–40` 对应前8000帧，而不是
全部20000帧。

更关键的是，公开数组实际满足原始速度矩方程：

- `p_new = M2 = ∫v²f dv`；
- `q_new = M3 = ∫v³f dv`；
- 它们不是文件名和正文容易让人理解成的中心压力与中心热流。

在 `t=0–24` 上代入原始矩方程，M0/M1/M2 的相对残差分别为
`0.0419/0.0337/0.0297`，相关系数均高于 `0.99945`。若把数组直接当成
中心矩代入论文的 primitive 方程则不自洽。这一接口差异解释了此前
“FNO 离线图几乎完美、流体闭环却明显错误”的一大部分原因。

按原始矩系统重写闭环后，当前自行实现的 FNO 仍会失稳：24模在
`t=4.60`、16模在 `t=4.80`、8模在 `t=12.23` 停止。也就是说，修正
变量定义是必要条件，但尚不足以复现论文闭环；论文未公开的网络实现、
数值耗散/滤波和训练细节仍然关键。

## 2. 同参数 CUDA-PIC 与 Gkeyll 对照

新增 `paper_match` 数据合同：`Nx=64`、每例 `26,214,400` 个粒子、
`dt=0.005`、输出到 `t=40`，在三张 GPU 上完成三个随机种子，GPU 峰值
约 `3.76 GiB`，无能量或相空间审计失败。

对比前先把 Gkeyll 原始矩转换为与 PIC 一致的中心矩：

`p = M2 - n u²`，`q = M3 - 3uM2 + 2nu³`。

修正后，PIC–Gkeyll 在 `t=0–15` 的中心热流相关系数为 `0.9913`，热流
梯度相关系数为 `0.9716`；到 `t=30–40` 分别降为 `0.9152` 和 `0.7259`。
热流梯度只保留 mode-1 时总相对差为 `0.1649`，到 mode-24 增为
`0.3548`；相应 PIC seed 噪声/信号从 `0.0123` 增为 `0.3315`。

因此 PIC 与 Vlasov/Gkeyll 并非“同一批无噪声标签换了求解器”：低阶矩
和线性期高度一致，但高阶矩在非线性期同时受到有限粒子噪声、粒子加载、
数值耗散及两类离散方法系统差异的影响。

## 3. PIC 离线闭合改进

本轮不再直接学习噪声较强的全频 `dq/dx`，而是：

- 三 seed 平均；
- 将中心热流 `q` 截断到 mode-24；
- 由 FNO 预测平滑 `q`，再做周期谱导数；
- 比较1、3、5帧低阶矩历史。

validation 结果为：单帧 `0.23421`、三帧 `0.18340`、五帧 `0.17271`。
五帧比单帧改善 `26.3%`；在已被第一轮打开过的 test 上为 `0.16838`、
相关系数 `0.98418`。这个 test 数字只作为回归指标，不再视为新 sealed
结论。

## 4. 闭环与微调消融

短时 `t=10` 验证显示：

- Poisson、`dt=0.02`：场能 log10 RMSE `0.4430`；
- Ampere、`dt=0.02`：`0.4441`；
- Poisson、`dt=0.005`：`0.4448`。

因此场求解形式和缩小时间步不是当前主要瓶颈。纯模型长时失稳；25% HP
仍有一例未完成 `t=60`；50% 和75% HP 均5/5稳定，其中75% HP 的验证
场能误差最低，为 `1.550`。

rollout 微调也没有通过独立验证：监督模型、window-5、window-20、
window-5 加场能损失在 `t=10` 的场能误差依次为
`0.4430/0.4474/0.4622/0.4450`。所有微调候选均被拒绝，避免用训练窗口
损失的下降冒充真实闭环提升。

## 5. 产出与下一步

本轮已经得到：

- 论文数据适配器、两种划分协议与 FNO 复现实验；
- 原始矩和 primitive 中心矩两套流体方程接口；
- 三例高粒子数、时间/网格匹配的 CUDA-PIC 对照数据；
- history-5 PIC 热流研究模型及完整消融；
- 修正为“时间横轴、空间纵轴、绝对误差独立色标”的可视化；
- 机器可读总结 `results/closure_fno_v2/final_report/study_summary.json`。

下一轮最有价值的路线不是继续盲目加大 FNO，而是：

1. 在 PIC 生成器中同时保存原始矩 M0–M3 和中心矩 n/u/p/q，并为每个
   变量写入定义、归一化和单位元数据；
2. 增加每组参数的 seed 数或粒子数，按 Fourier mode 给训练损失做
   噪声方差加权；
3. 用长窗口、自由运行状态训练稳定性，并把场能、守恒残差和谱半径作为
   模型选择指标；
4. 新增独立的参数外推/时间外推数据，禁止同轨迹随机帧混入 test；
5. 若要严格复现论文闭环，需要作者代码或至少确认其 raw/central moment
   约定、FNO 逐层结构、滤波和流体时间步。
