# Huang 2025：Gkeyll 严格单案例复现实验

## 结论

已用 CUDA Gkeyll 完成一个且仅一个可用于后续研究的非线性 Landau
阻尼案例：`k=0.35, A=0.10, Nx=Nv=64, v∈[-6,6], t=0..40`。正式数据含
`0..8000` 共 8001 个完整时刻，每个时刻都有分布函数、场和 M0-M3，六类
文件均无缺帧。

这个实验确认了此前 PIC 图中“没有论文式涡旋”的一个重要原因：论文
Fig.4 在非线性阶段裁剪的是正相速度支 `v_x≈[2,4.5]`，俘获粒子岛中心
约在 `v_x≈3.5`。若只画完整 `[-6,6]` 或错误裁剪为 `[-3,3]`，结构会被
Maxwellian 背景和色标压住。新 Gkeyll 数据在 `t=30,35,40` 清楚出现与论文
同类的弯曲/闭合相空间结构，说明该案例确实进入非线性阶段。

## 严格参数与数值假设

| 项目 | 数值 |
|---|---:|
| 波数 `k` | 0.35 |
| 初始密度扰动 `A` | 0.10 |
| 空间区间 | `[0,2π/k]`，周期边界 |
| 速度区间 | `[-6,6]` |
| 网格 | `64×64` |
| 终止时间 | 请求 40，实际 40.00053894 |
| 输出 | 8001 帧，目标间隔 0.005 |
| 动力学系统 | 无碰撞 Vlasov-Ampère |
| 时间推进 | RK3 |
| DG | p2 serendipity |
| CUDA | A800，正式运行物理卡 2 |

论文没有报告 DG 阶数，因此 p2 serendipity 不是论文中可逐字核验的参数，
而是采用官方 Gkeyll Landau 回归案例的明确假设。Gkeyll 版本固定为提交
`8d7adbc7f4822d34b5eadb6a897d5ecb16b44d02`。

Gkeyll 的 `nFrame` 触发器不会强制内部时间步对齐输出间隔。短预检和一次
完整失败审计发现，`cflFrac=0.573` 后期时间步增至约 0.00536，只写出
7594 帧。因此正式案例使用有实测依据的 `cflFrac=0.53`，全程内部步长
保持在 0.005 以下，最终恰好写出 8001 帧。失败尝试的 2.2 GB 原始帧已
移入系统回收站，仅保留输入、统计和日志，避免把它误当成第二个数据集。

## 数值与文件审计

- 更新步数 8207，正式更新耗时 569.77 s；写出耗时 2.59 s。
- RK3 stage-3 失败为 0；stage-2 有 36 次约 1% 的自适应重试，求解器接受
  后正常完成。
- 分布函数、场、M0、M1、M2、M3 各 8001 帧，六类缺失数均为 0。
- 原始 `.gkyl` 文件 48009 个，共 2,253,999,411 bytes（目录显示约 2.3 GB）。
- 整合 HDF5 为 27,273,666 bytes（约 27 MB）。
- 初始 M0 对解析 cell-center 密度的相对 L2 为 `1.97×10⁻9`。
- 初始 M1 RMS 为 `4.55×10⁻17`，M3 RMS 为 `1.02×10⁻16`。
- 初始 M2 对 M0 的相对 L2 为 `7.29×10⁻8`。

## 与 Huang 公开 A01 数据的比较

公开 MAT 没有时间和空间相位元数据。这里按论文所述 `Δt=0.005` 使用前
8001 行，并从 `t=0` 密度确定一次固定的 59 格周期平移；后续所有变量和
所有时刻都使用同一平移，没有逐帧配准。

| 变量 | 全时空相对 L2 | 全时空相关系数 |
|---|---:|---:|
| 密度 M0 | 0.004109 | 0.985076 |
| 速度 M1/M0 | 0.212911 | 0.983007 |
| 原始二阶矩 M2 | 0.014625 | 0.984798 |
| 原始三阶矩 M3 | 0.214613 | 0.982640 |

速度和 M3 以零为背景、整体范数较小，因此相对 L2 对小幅值/相位差很
敏感；相关系数更能反映时空形态的一致性。四个变量的相关系数均超过
0.9826，但晚期仍有可见相位差，不能宣称逐点精确复现。

场能统一采用论文 Fig.4 和 Gkeyll 的 `∫|E_x|²dx` 定义后：

- 新 Gkeyll 初值：0.7327329804；
- 公开矩 Poisson 重构初值：0.7327329040；
- 全时段相关系数：0.987479；
- 全时段相对 L2：0.153417；
- `log10` RMSE：0.582008（零点附近对微小相位差很敏感）。

场能曲线正确显示先衰减、约 `t≈23–25` 停止衰减、随后增长的非线性回弹，
并且振荡周期与公开数据接近。晚期峰值幅度和极小值时间仍有偏差，可能
来自论文未公开的 Gkeyll 版本、DG/数值耗散细节以及公开 MAT 缺少元数据。

## 可用于训练的数据接口

整合 HDF5 同时保留两套定义：

- `raw_moments/M0..M3 = ∫v^m f dv`，对应公开 MAT 实际满足的原始矩方程；
- `central_moments/density, velocity, pressure, heat_flux`，其中
  `p=M2-nu²`，`q=M3-3uM2+2nu³`，可直接与 PIC 的中心矩接口比较。

后续若用这一条轨迹训练 FNO，应把它定位为“同轨迹方法/接口验证”，不能
用随机帧切分声称参数泛化。真正的泛化实验仍需要独立的 `k/A` 组合，但这
次按要求没有生成参数扫掠或大量 Gkeyll 案例。
