# FNO 热流闭合复现：问题发现与解决

> **一句话结论：**按论文颗粒度对齐 Gkeyll 数据、中心矩、`∂xq` 标签、三矩方程和 RK4 闭环后，我们在同案例、同轨迹上复现了非线性场能回升；目前尚未解决的是未见时间和未见参数下的长期闭环泛化。

## 1. 主要问题是怎样发现并解决的

| 发现的问题 | 诊断证据 | 解决办法 | 解决后的结果 |
|---|---|---|---|
| 数据源与非线性不对齐 | PIC 高阶矩噪声大；弱扰动多数只出现相混合条纹 | 先用论文 Gkeyll 锚点 `k=0.35, A=0.10, t=0–40` 的完整强非线性轨迹复现；PIC 留作域迁移 | 同轨迹出现阻尼—最低点—回升 |
| 物理量语义不对齐 | 原始 `M2/M3` 与中心 `p/q` 混用；预测 `q` 后求导会放大噪声 | 使用中心矩 `p=M2−nu²`、`q=M3−3uM2+2nu³`，直接监督压力方程所需的 `∂xq` | 闭合 rel-L2 为 `0.00458`，相关系数为 `0.99999` |
| PDE 与调用粒度不对齐 | Poisson/Ampère、primitive/守恒形式及每整步一次闭合混杂 | 对齐 primitive 三矩方程和 Ampère；每个 RK4 stage 调用 FNO；第一步使用真实初始闭合 | 真值 closure oracle 的场能误差约为 `10⁻³`，排除 PDE 写错 |
| 网络结构与频谱不对齐 | GroupNorm/GELU 和高模输出导致闭环敏感 | 改为论文明确的4层、ReLU、无 GroupNorm；扫描 8/12/16/24 后部署 mode 8 | Round 6 相对旧结构改善 `58.1%`；最佳场能误差为 `0.0379` |
| 图很好，但评估口径偏乐观 | 完整轨迹训练后仍在同一案例验证；最佳 seed 掩盖训练波动 | 同时报告3-seed中位数，并补做 `t<24` 时间外推和整案例留出 | 同轨迹中位数为 `0.1788`；严格泛化误差升至 `0.44–0.96` |

## 2. 与论文的物理合同是否对齐

- **已经对齐：**1D1V Gkeyll Vlasov–Ampère、固定中和离子、`k=0.35`、`A=0.10`、`Nx=Nv=64`、`v∈[−6,6]`、`t≤40`、中心矩 `{n,u,p}→∂xq`、训练采样 `Δt=0.005`、RK4 闭环 `Δt=0.002`。
- **工程性选择：**论文正文未披露 width/modes；我们训练使用 `width=128, modes=32`，部署额外采用 mode 8。严格时间外推和整案例留出是我们增加的评估，不是论文主图的评估协议。

改善主要来自数据合同、物理合同、数值合同和评估合同同时对齐，而不是单纯扩大 FNO。

FNO 与真值近乎重合，HP 不能保持非线性回升。场能 log10 RMSE：FNO `0.0379`，HP `1.1773`。

## 4. 最终判断

- **已经解决：**严格按论文单案例训练时，FNO 闭合能够正确嵌入三矩流体方程，复现非线性场能回升，并显著优于 HP。
- **尚未解决：**闭合对后期未见状态和未见参数案例的长期泛化；当前最好曲线不能代表通用样本外性能。
- **下一步重点：**扩充强非线性案例并保持整轨迹划分；用短闭环验证和偏移状态训练约束能量交换与相位，而不是继续只优化逐帧 `∂xq` 误差。
