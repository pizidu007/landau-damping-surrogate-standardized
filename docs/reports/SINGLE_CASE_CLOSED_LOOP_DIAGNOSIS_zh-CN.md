# Huang 2025 单案例闭环推进故障诊断

## 结论

当前严格单案例闭环的主要问题不在三矩流体方程、Poisson/Ampère 电场更新、
RK4 步长或第一步初始化，而在于 **FNO 从真实轨迹上的小回归误差，经过闭环
反馈转化为模型轨迹上的分布外误差**。误差首先进入压力方程，随后通过压力梯度
传播到速度，再传播到密度和电场；场能图上看到的偏差是这一反馈链的后果。

论文参数 `k=0.35, A=0.10`、中心矩、`dt=0.002` 的精确审计结果是：

- 同一流体求解器逐 RK 子步使用真实 `∂q/∂x`，推进到 `t=40` 后状态相对
  L2 只有 `5.35e-5`，场能 log10 RMSE 为 `0.00162`；
- FNO 输入始终取 Gkeyll 真实低阶矩时，闭合相对 L2 为 `0.00291`；
- FNO 输入改为自己推进出的低阶矩后，闭合相对 L2 增至 `0.78355`；
- 闭环路径相对真实路径的闭合漂移也是 `0.78354`，说明几乎全部新增误差
  都来自状态反馈，而不是 FNO 在真实轨迹上的拟合误差。

因此不存在一个“把某个符号改正就能复现”的单一 PDE bug。当前第一处实质性
错误是模型从约 `t=5.3` 起对微小离轨状态产生了明显不同的热流梯度。

## 1. 故障首次出现在哪里

24 模闭环的时间顺序如下：

| 事件 | 首次时间 |
|---|---:|
| 闭环输入上的 `∂q/∂x` NRMSE 超过 1% | `t=5.314` |
| 归一化状态距离超过 0.1% | `t=5.954` |
| 归一化状态距离超过 1% | `t=8.346` |
| 场能绝对 log10 误差超过 0.01 | `t=9.054` |
| 闭环 `∂q/∂x` NRMSE 超过 50% | `t=9.386` |
| 归一化状态距离超过 10% | `t=10.420` |

因果顺序是“闭合漂移 → 压力漂移 → 速度/密度漂移 → 场能漂移”，不是场求解器
先错后反过来污染闭合。真实轨迹输入上的逐时 NRMSE 从未越过 1%，所以离线图
很好与闭环失败并不矛盾。

## 2. 哪条方程放大了误差

三矩系统中 FNO 只直接替换压力方程的热流梯度项：

`p_t = -u p_x - 3 p u_x - (∂q/∂x)_FNO`。

在 `t=0–5`，真实轨迹上的闭合误差 RMS 仅为总压力 RHS RMS 的
`3.26e-4`；在 `t=5–10` 也只有 `6.86e-4`。它虽然很小，却是持续、相干的
源项误差，而 Landau 阻尼后期场能很小，场的相位和谷值对这种误差极为敏感。
压力偏差经 `-(1/n)p_x` 进入速度方程，速度再经 `-(nu)_x` 进入密度方程，
最终改变电场和下一次 FNO 输入，形成正反馈。

这也解释了为什么总能量守恒良好并不能保证轨迹正确：错误闭合仍然可以在场能
和粒子热能之间进行近似守恒但相位错误的能量交换。

## 3. 高 Fourier 模为什么加剧闭环失稳

在真实轨迹上：

- mode 1–8 的闭合相对误差为 `0.00274`；
- mode 9–24 的闭合相对误差为 `0.03301`。

在闭环轨迹上：

- mode 1–8 的误差升至 `0.63789`；
- mode 9–24 的误差升至 `15.3873`。

因此高模不是主要物理信号，却具有最大的离轨增益。截断到 mode 8 后，归一化
状态距离超过 0.1% 的时间从 `t=5.954` 推迟到 `t=9.172`，超过 1% 从
`t=8.346` 推迟到 `t=14.260`；这就是 8 模在 `t≤20` 明显改善的原因。
但到 `t=40` 仍会漂移，说明低通滤波只是提高稳定余量，没有修复训练分布问题。

## 4. 已排除的实现问题

### 4.1 流体方程与 RK4

对论文同参数轨迹进行真实热流 oracle 推进：

| 最大模 | 场求解 | 状态相对 L2 | 场能 log10 RMSE |
|---:|---|---:|---:|
| 8 | Poisson | `5.25e-5` | `0.00147` |
| 8 | Ampère | `5.26e-5` | `0.00168` |
| 24 | Poisson | `5.30e-5` | `0.00183` |
| 24 | Ampère | `5.35e-5` | `0.00162` |

真实热流能把流体解锁定在 Gkeyll 轨迹上，说明中心矩方程、符号、归一化和
时间推进整体自洽。

### 4.2 每 RK 子阶段调用 FNO，还是每步只调用一次

论文文字可能理解为每个完整时间步计算一次 FNO 并在 RK4 内冻结。消融结果：

- 每个 RK 子阶段重新计算：场能 log10 RMSE `0.4275`；
- 每个完整时间步冻结：场能 log10 RMSE `0.4518`。

冻结没有改善，因此这一实现歧义不是根因。

### 4.3 第一步使用真实热流

严格复现已按论文描述在第一步使用真实初始热流。误差在 `t≈5` 后才显著，
第一步初始化不是当前瓶颈。

## 5. 我们此前确实做错过的一处接口

Zenodo 中 `A005_data.mat` 和 `A01_data.mat` 的 MD5 都是
`6370e709ce0a825148917fabc8638a2a`，本地 SHA-256 也完全一致；公开资产实际
没有两条独立的 `A=0.05/A=0.10` 轨迹。进一步代入矩方程可知，公开文件的
`p_new/q_new` 满足原始矩 `M2/M3` 方程，不宜直接当作论文式 (3) 的中心压力
和中心热流。

这确实解释了早期“离线 FNO 好、闭环方程不自洽”的一部分问题。当前严格
单案例已改用自行生成并明确标注的中心矩数据，所以它不是现阶段剩余误差的
原因。

## 6. 为什么论文中看起来可以做到

### 6.1 论文测试本质上是同轨迹再采样，不是新轨迹外推

论文用 `k=0.35, A=0.10` 的同一条 `t=0–40` 轨迹，以 `dt=0.005` 取得
8000 帧训练，再以 `dt=0.002` 在同一 `t=0–40` 区间闭环 20000 步。非线性
阶段 `t=30–40` 已包含在训练轨迹中，因此这主要检验同轨迹闭环和时间步再采样，
不是对未见时间段或未见参数的预测。我们的随机交错单轨迹 test 同样可达到
`0.00292`，但严格因果的 `t=30–40` test 为 `1.58`，恰好说明两种问题难度
完全不同。

### 6.2 论文没有公开足够的数值实现

正文只明确四个 Fourier 层、实空间线性支路和 ReLU；没有给出 Fourier 模数、
隐层宽度、训练 epoch、batch、优化器、归一化、空间离散、抗混叠、滤波或完整
闭环代码。我们的模型使用 GELU 和额外 GroupNorm，不能声称与作者网络逐层
相同。Zenodo 只提供数据文件，没有训练代码、权重或流体求解器，因此论文图
无法从公开资产严格独立复核。

### 6.3 公开数据自身存在可复现性异常

记录声称两个文件对应线性与非线性案例，但两个下载文件哈希完全相同；文件内
变量语义与正文中心矩定义也有冲突。不能据此断言作者内部实验错误，但这意味着
外部研究者拿到的材料不足以重建作者实际流水线。

### 6.4 论文结果也不是全程无误差

论文本身说明 Fluid+ML 与 Vlasov 曲线在两个 bounce periods 后因 bouncing
frequency 不同而开始偏离。因此它展示的是一个较好的同案例闭环，而不是严格
稳定、任意长时或跨参数的通用闭合。

## 7. 下一步最有判别力的改进

1. **严格复现网络结构**：先移除 GroupNorm、改用 ReLU，并对 width/modes 做
   小型扫描；这是当前与论文明确描述不一致的实现点。
2. **全 8000 帧同案例拟合**：论文没有说明保留验证帧。为了复现图，先用全部
   `t=0–40` 帧训练，再另设真正的参数外测试；不要把复现任务与泛化任务混在一起。
3. **闭环/扰动训练**：在真实状态上加入与早期 rollout 相当的小扰动，训练
   `FNO(n+δn,u+δu,p+δp)` 返回能把系统拉回真实轨迹的闭合；加入 10–100 步
   rollout loss，而不只优化逐帧 MSE。
4. **谱加权和稳定性筛选**：主训练限制到 8–12 模，高模按信噪比降权；模型选择
   同时使用离线误差、短闭环误差和状态到闭合的局部增益。
5. **向作者索要代码/权重**：重点确认 raw/central moment、FNO width/modes、
   归一化、滤波、RK4 内 FNO 调用频率和空间离散。没有这些信息，最多只能做到
   方法学复现，不能声称数值逐图复现。
