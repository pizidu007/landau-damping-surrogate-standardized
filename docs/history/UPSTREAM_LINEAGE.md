# 项目来源与演化

当前项目是在 [kaneman777/landau-damping-surrogate](https://github.com/kaneman777/landau-damping-surrogate) 基础上的修改和改进。该上游项目又说明其 PIC 部分 fork 自 [Antoine Tavant 的 1D-PIC electrostatic](https://github.com/antoinelpp/1d-pic-electrostatic)。

本地固定上游快照、commit 和逐文件哈希见：

- `reference/upstream/UPSTREAM_SOURCE.json`
- `reference/upstream/UPSTREAM_TREE.sha256`
- `reference/DIFFERENCES.md`

项目根目录是唯一的当前维护版本，`reference/` 仅作为材料和差异追溯依据。
