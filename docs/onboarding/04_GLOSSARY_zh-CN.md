# 术语与符号速查

[返回学习路线](README.md) · [背景概念](01_BACKGROUND_zh-CN.md) · [任务定义](03_TASK_DEFINITIONS_zh-CN.md)

这是本项目语境下的速查表。同一个字母或缩写在不同阶段可能含义不同；
遇到冲突，先确定数据族、模型任务和函数接口。

## 1. 物理量与数学符号

| 词或符号 | 在这里表示什么 | 容易混淆的地方 |
|---|---|---|
| 1D1V / 1x1v | 一维位置加一维速度的动力学问题 | 不是只有一个标量随时间变化 |
| 相空间 / phase space | 位置与速度组成的空间，本项目为 `(x,v)` | 普通流场通常只有位置轴，没有速度分布轴 |
| `f` | 完整粒子分布函数 | 不能把单个粒子的轨迹当作 `f` |
| `f_bg` | 早期分布代理使用的背景分布 | 不等于每个案例每个时刻重新拟合的背景 |
| `delta_f` | `f-f_bg`，分布的扰动 | 可以为负；完整 `f` 的非负性是另一件事 |
| Maxwellian | 本项目初态使用的热平衡速度分布 | 后续演化不被强制保持 Maxwellian |
| `K` / 常见旧名 `k` | 当前无量纲基波数，`K=k_phys*lambda_D` | 大小写和单位需看数据合同；不要与模态编号混用 |
| `alpha` / `α` | 初始相对密度扰动幅度 | 不等于所有未来时刻的场幅，也不单独决定物理类别 |
| `L` | 周期盒长 `2*pi/K` | 不同 K 对应的真实盒长不同 |
| `m` / mode | 离散空间 Fourier 谐波编号 | `m=1` 的物理波数是 K，`m=16` 的物理波数是 16K |
| `M0,M1,M2,M3` | 对 `v^r*f` 积分得到的原始矩 | Round 10 协议还用 M0/M1/M2 命名实验组，要根据上下文区分 |
| `n` | 密度，等于 M0 | 不是归一化后的网络特征槽 |
| `u` | 平均流速，等于 M1/n | 某些无量纲定义还用 u 表示速度坐标 v/v_th；看所在配置 |
| `p` | 压力，等于 M2-n*u² | 不等于 M2，也不等于 T |
| `T` | 温度，p/n | HDF5 的 `[n,u,T,q]` 第三通道存的是它 |
| `q` | 本仓库约定的第三中心矩热流 | 不额外乘 1/2；也不同于电荷符号 q_s |
| `g` / `dqdx` | 闭合文档中的热流梯度 dq/dx | 数据生成配置的归一化表另用 g 表示缩放后的分布函数 |
| `E` | 电场 | 场强、场能、总能量不是同一量 |
| `W_E` | 电场能量或能量密度，须注明积分/平均 | 误差和跨案例比较需保持同一口径 |
| `U` | 某个任务的状态向量 | Round 11 为 `[n,u,p,E]`，Round 10 为 `[M0,M1,M2,E]` |
| `theta` / `θ` | 数学公式中的网络可训练参数 | 不是额外输入的初始物理参数 |

## 2. 数值求解与物理约束

| 术语 | 含义 | 在本项目怎样用 |
|---|---|---|
| Vlasov 方程 | 分布函数在位置和速度空间中的演化方程 | 完整动力学参考的基础 |
| PDE / 偏微分方程 | 含有多个自变量方向导数的方程 | 本项目含时间、空间以及动力学模型中的速度方向 |
| ODE / 常微分方程 | 对一个自变量求导的演化方程 | 空间离散后，很多网格值组成一个随时间推进的 ODE 系统 |
| Poisson / Gauss 约束 | 密度与电场空间导数的关系 | 检查电荷与电场是否一致，构造初始 E |
| Ampère 更新 | 由电流更新电场的时间演化 | Round 11 将 E 作为第四个场推进，并去除平均电流 |
| PIC | Particle-in-Cell，用计算粒子采样分布并与网格场耦合 | 历史分布与部分热流实验的数据来源 |
| Gkeyll | 仓库使用的外部动力学求解软件 | 产生当前 continuum_v1 参考；不是一个神经网络 |
| DG | Discontinuous Galerkin，单元内多项式表示的离散方法 | Gkeyll 输出的系数需正确处理，不能都当成网格节点值 |
| 闭合 / closure | 估计有限矩方程中缺失的高阶项 | 当前学习 dq/dx，让三矩方程继续推进 |
| HP | Hammett–Perkins 热流闭合 | 早期实验中的传统参考闭合；其系数、滤波和混合比例应按对应实现读取 |
| RHS | Right-hand side，时间演化方程的右端 | 网络闭合进入压力方程 RHS |
| RK4 | 四阶 Runge–Kutta 时间推进 | 默认每个流体步计算四次右端，中间状态同样需要检查 |
| `dt` | 当前流体积分的小步长 | 不等于文件保存帧间隔 |
| `DeltaT` / 宏步 | 状态代理一次跨越的预测时长 | Round 10 的概念，不能直接套成 Round 11 的闭合目标 |
| `output_dt` | 保存或比较输出的时间间隔 | Round 11 全程输出为 0.1，流体 dt 为 0.02 |
| closure interval | 闭合值重新估计的间隔 | 大于 dt 时可以减少网络调用，但需重新验证 |
| low-pass / 低通 | 去掉超过指定模态的空间分量 | 可能改善数值行为，也可能丢失真实信号 |
| positivity / 正性 | 完整分布、密度或压力的非负/正值要求 | 要说明检查哪个量；训练软惩罚不等于部署硬保证 |
| clipping / clamp / 钳位 | 把变量强行限制在一个范围 | 当前 Round 11 不用钳位把失败轨迹改成“成功” |
| reflection equivariance / 反射等变 | 输入按规定反射后，输出作对应反射 | n,p 与 u,E 的变号规则不同；约束并不免费 |
| oracle | 用参考闭合驱动求解器的诊断实验 | 隔离数值链路问题，不作为自主学习模型的结果 |

## 3. 数据、机器学习与实验管理

| 术语 | 含义 | 常见误读 |
|---|---|---|
| surrogate / 代理 | 用较便宜的计算近似原任务 | 速度与准确度都要实际验证 |
| FNO | 用 Fourier 层学习场到场映射的网络 | 不自动满足全部 PDE、守恒或泛化条件 |
| PINN | 常指以物理方程残差等构造训练约束的神经网络方法 | 本项目使用 FNO 加可微分求解器，不能只因“加入物理”就把所有模型都叫 PINN |
| label / target / 标签 | 训练或打分时用来比较的参考输出 | 当前闭合标签是 g，轨迹训练的目标还包含 U；二者不同 |
| loss / 损失 | 训练时优化器试图减小的标量目标 | 小损失不自动等于完整验证的所有指标通过 |
| batch | 一次并行计算的一组样本 | batch 数目不等于独立案例数，也不等于历史长度 |
| epoch | 一轮约定的训练样本遍历或采样覆盖 | 各阶段的采样规则不同；相同 epoch 数不必然意味着相同计算量 |
| optimizer / 优化器 | 根据梯度调整网络参数的算法 | 不是用于推进物理时间的 RK4 |
| backpropagation / 反向传播 | 计算损失对可训练参数的导数 | 多步训练需要梯度经过多次网络调用与物理推进 |
| hyperparameter / 超参数 | 人为选择的结构、学习率、窗口长度等设置 | 不同于通过训练学出的权重，也不同于物理参数 K/alpha |
| width | 网络隐藏特征通道数 | 不是物理网格宽度，也不是历史长度 |
| layers | 网络块数 | 不同于 RK4 的四个中间计算阶段 |
| case / trajectory | 一组初始条件的一条时间轨迹 | 不能把同 case 的相邻帧当成独立参数测试 |
| frame | 一条轨迹中的一个时间切片 | 八个历史槽不一定就是连续八帧 |
| history span | 最早历史槽距离当前的物理时长 | 与槽的数量、时间间隔是三种量 |
| valid mask | 标记历史槽是否来自合法过去时刻 | 初态填充值相同，不代表所有过去槽真实存在 |
| normalization | 为网络特征和标签确定数值尺度 | 与物理无量纲化不同；统计量只从 train 估计 |
| teacher forcing | 把参考状态作为某步输入的训练方式 | 不能与递归吃自己预测的自由运行混称 |
| free rollout | 初始信息给定后，用自身预测连续推进 | 不能在中途回灌真实状态还称全程自主 |
| burn-in | 有梯度窗口前的自主刷新段 | 本项目训练中无梯度刷新；不是部署领取真实历史 |
| rollout curriculum | 逐步增加训练中自由推进窗口的课程 | 短窗课程通过不意味着 t=80 评价通过 |
| detach | 切断张量与之前计算的梯度联系 | 形式上跑很多步但中途 detach，不是完整窗口反传 |
| gradient checkpointing | 通过反向时重算中间值减少显存 | 与磁盘中的模型 checkpoint 不是同一种“检查点” |
| checkpoint 文件 | 权重及可能的配置、优化器、归一化等 | 只有模型结构代码，不等于已有训练好的权重 |
| seed | 控制随机性的种子 | 共享预训练权重的三个 seed 不是独立从零训练 |
| pilot | 较小预算的先导实验 | 完成 pilot 不等于通过正式质量门 |
| ablation / 消融 | 在控制其他条件时改变一个因素 | 同时改数据、网络、步长，难以归因 |
| train / validation | 用于拟合参数 / 用于选择与检查 | validation 被用于选择，不能再当作完全独立最终证据 |
| diagnostic test | 已经打开、用于开发诊断的旧测试集 | 名称含 test 不代表仍然密封 |
| holdout / sealed test | 冻结决策后才使用的独立评价数据 | 一旦根据它调参，就改变了原本的评价角色 |
| QC | Quality control，数据质量检查 | 输入文件存在并不代表数值参考合格 |
| quality gate / 质量门 | 事先写明的阶段验收条件 | 不能因某候选失败就临时放宽并沿用原成功口径 |
| manifest / provenance | 资产清单 / 来源、配置、哈希记录 | 同名文件不一定同内容，要核对版本与哈希 |

## 4. 指标与结论

| 术语 | 含义 | 阅读时要问 |
|---|---|---|
| relative L2 | 误差范数除以指定参考范数 | 分母是完整状态、扰动，还是每通道尺度？ |
| RMSE | 均方根误差 | 对什么量、在哪些时间和案例上计算？ |
| log10-RMSE | 对 log10 后的量算 RMSE | 地板怎么设？0.3 不是 0.3% 的误差 |
| phase MAE | 相位绝对误差的平均，通常用 rad | 低信号被怎样处理？预测没信号是否被记录？ |
| completed fraction | 满足完成与物理条件的案例比例 | 是全部推进到同一终点，还是只存了成功前缀？ |
| paired comparison | 在双方共同完成的同一案例上比较 | 是否同时报告了各自失败率？ |
| drift / 漂移 | 守恒量相对初值的变化 | 绝对/相对、空间积分/平均、最大值/均值是否一致？ |
| interpolation / 插值泛化 | 在已有参数覆盖范围内预测新案例 | 不等于看过同一轨迹的临近帧 |
| extrapolation / 外推 | 在训练覆盖范围之外评价 | 与范围内插值应分开报告 |
| wall time | 实际经过的墙钟时间 | 是否 GPU 同步，是否含加载、传输、写盘？ |
| speedup | 在可比任务下的耗时比 | 是否同时满足精度门和相同输出要求？ |
| negative result / 负结果 | 假设或候选在约定实验中未达标 | 应保留；有限负结果不是一般不可能性证明 |

更精确的公式、数值阈值和聚合方式见[任务定义](03_TASK_DEFINITIONS_zh-CN.md)。
